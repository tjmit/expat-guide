If you are a Portuguese tax resident, the default is yes: you file the annual IRS return (Modelo 3) and report worldwide income, unless a listed exemption from filing applies.

## Citations and legal explanation

**Details:** gov.pt: residents file online and report income obtained outside Portuguese territory too; non-residents file only for Portuguese-source income not subject to withholding. Not obliged to file if only income taxed by withholding, or employment/pension income up to EUR 8,500, among other listed cases; joint filers are excluded from that relief. Residency is decided by the 183-day or habitual-abode tests (I1), not by what an employer reports. RGIT art. 116 n.º 3 says the late-filing fine does not apply if you are exempt from filing under art. 58 CIRS for that year. A US citizen must also file the US return regardless (A1). If someone tells you that you owe nothing in Portugal, see J2 and J3 before relying on it.
